# Panduan Re-Create Database Supabase

Karena skema database saat ini berantakan atau tidak sinkron dengan *source code*, kita akan melakukan **Reset Total** (Wipe & Re-create). 

Ikuti langkah-langkah mudah berikut ini:

### Langkah 1: Buka Supabase SQL Editor
1. Login ke [Supabase Dashboard](https://supabase.com/dashboard)
2. Masuk ke *Project* Anda.
3. Di menu sebelah kiri, klik menu **SQL Editor** (ikon `< >` / terminal).
4. Klik tombol **New Query**.

### Langkah 2: Copy-Paste dan Jalankan Script Ini
Copy seluruh kode SQL di bawah ini, paste ke dalam SQL Editor, lalu klik tombol **Run** (atau tekan `Cmd+Enter` / `Ctrl+Enter`).
